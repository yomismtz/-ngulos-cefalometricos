QUÉ CUBREN LAS POLÍTICAS

AlmacenamientoDónde permanecen los estudios y cómo puede eliminarlos el usuario.
ComparticiónQué ocurre cuando el usuario exporta un informe o lo entrega a otra aplicación.
Seguridad y soporteBuenas prácticas, límites de seguridad y canal público para consultas.

IMPORTANTE

Una radiografía puede contener datos relacionados con la salud.

Para docencia, demostraciones y pruebas se recomienda utilizar material anonimizado. Si se trabaja con información identificable, el usuario debe contar con las autorizaciones y bases legales aplicables antes de almacenarla o compartirla.
