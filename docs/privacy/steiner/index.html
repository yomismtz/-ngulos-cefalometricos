1. Alcance y responsable

Esta política describe las prácticas de privacidad de YOM Steiner, aplicación Android identificada como com.yomceph.cefalometrico, publicada bajo YOM Apps.

YOM Steiner está enfocada en cefalometría lateral y análisis de Steiner. Esta política cubre el funcionamiento de la aplicación y no sustituye las políticas de servicios externos que el usuario decida utilizar.

2. Datos que puede manejar la aplicación

La aplicación puede procesar información seleccionada, introducida o generada por el usuario durante un estudio, incluyendo:

RadiografíasImágenes laterales seleccionadas por el usuario para realizar el análisis.
Datos del estudioNombre del estudio e identificador o pseudónimo opcional.
TrazadoPuntos cefalométricos, referencias, líneas y datos de calibración.
ResultadosÁngulos, mediciones y resultados derivados del análisis de Steiner.

Las radiografías y los resultados derivados pueden constituir información personal o relacionada con la salud si contienen o permiten vincular información a una persona.

3. Para qué se utiliza la información

Los datos se utilizan para ejecutar las funciones solicitadas dentro de YOM Steiner: visualizar la radiografía, calibrar, colocar puntos cefalométricos, calcular mediciones, revisar resultados, guardar o eliminar el estudio y generar archivos para exportación.

El desarrollador no utiliza el contenido de los estudios para publicidad, creación de perfiles o entrenamiento de modelos.

4. Procesamiento y almacenamiento

En la versión actual, los datos del estudio se procesan y almacenan principalmente de forma local en el dispositivo. YOM Steiner no crea cuentas, no integra anuncios, no utiliza analítica ni telemetría del desarrollador y no envía automáticamente radiografías o resultados a servidores del desarrollador.

Las copias de seguridad de los datos privados de la aplicación están desactivadas en la configuración actual documentada del proyecto.

5. Exportación, compartición y terceros

El usuario puede decidir exportar imágenes, informes o resultados y compartirlos mediante otras aplicaciones o servicios de su dispositivo. La transferencia se produce únicamente cuando el usuario inicia esa acción.

Después de entregar un archivo a correo, mensajería, almacenamiento en la nube u otro servicio elegido por el usuario, el tratamiento posterior se rige por las políticas del tercero seleccionado.

El desarrollador no vende ni alquila radiografías, datos de estudio o resultados que la aplicación no le transmite automáticamente.

6. Conservación y eliminación

Los estudios guardados permanecen en el dispositivo hasta que el usuario los elimina, borra los datos de la aplicación o desinstala la aplicación. La versión actual no conserva una copia de servidor del estudio.

Los archivos exportados fuera de YOM Steiner deben eliminarse desde la aplicación o servicio donde el usuario haya decidido guardarlos o compartirlos.

7. Seguridad y uso responsable

El procesamiento local reduce la necesidad de transmitir el contenido del estudio al desarrollador, pero ningún dispositivo o sistema de almacenamiento puede garantizar seguridad absoluta.

Para docencia, demostraciones y pruebas se recomienda utilizar radiografías anonimizadas. Si se utiliza información identificable, el usuario es responsable de contar con las autorizaciones y medidas de protección aplicables.

8. Menores

YOM Steiner no está diseñada específicamente para niños ni como servicio infantil. Está orientada principalmente a estudiantes universitarios, profesionales y adultos en formación odontológica o áreas relacionadas.

Si un estudio incluye una radiografía de una persona menor de edad, quien incorpore esa imagen es responsable de contar con la autorización correspondiente.

9. Uso educativo y de apoyo profesional

YOM Steiner no sustituye el juicio clínico y no debe utilizarse como única base para diagnosticar o tratar una afección. La exactitud de los resultados depende de factores como la calidad radiográfica, la calibración y la correcta colocación de puntos cefalométricos.

10. Cambios de esta política

La política se actualizará cuando cambien las funciones o las prácticas de datos. Si una versión futura incorpora cuentas, servicios en la nube, sincronización, publicidad, analítica, telemetría u otra transmisión de datos, esta página y las declaraciones correspondientes en Google Play deberán revisarse antes de distribuir esa versión.

11. Contacto

Para consultas relacionadas con privacidad, funcionamiento o solicitudes sobre esta política puede utilizar el canal público de soporte del proyecto en GitHub. Cuando la aplicación se encuentre publicada, los datos de contacto del desarrollador también se muestran en su ficha oficial de Google Play.
