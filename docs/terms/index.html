TÉRMINOS Y CONDICIONES

Condiciones de uso de YOM Apps.

Estos términos regulan el uso del sitio web y de las aplicaciones YOM Análisis Radiográficos y YOM Steiner.

1. Aceptación

Al acceder al sitio de YOM Apps o instalar, abrir o utilizar YOM Análisis Radiográficos o YOM Steiner, el usuario acepta estos Términos y Condiciones y la Política de Privacidad aplicable. Si no está de acuerdo con ellos, debe dejar de utilizar el sitio y las aplicaciones.

2. Servicios cubiertos

Estos términos se aplican al sitio web de YOM Apps y a las aplicaciones Android YOM Análisis Radiográficos, identificada actualmente como yom.Analisis, y YOM Steiner, identificada actualmente como com.yomceph.cefalometrico.

Las aplicaciones ofrecen herramientas relacionadas con visualización, trazado, medición y análisis de estudios radiográficos odontológicos y cefalométricos, así como funciones de almacenamiento local y exportación iniciadas por el usuario.

3. Uso educativo y de apoyo profesional

Las aplicaciones están destinadas a fines educativos, de formación y de apoyo al análisis. No sustituyen el juicio clínico de un profesional cualificado y no deben utilizarse como única base para diagnosticar, tratar, curar o prevenir una enfermedad o afección.

El usuario es responsable de revisar la calidad de las imágenes, la correcta colocación de puntos, calibraciones, mediciones, referencias y resultados antes de tomar cualquier decisión académica o profesional.

Las aplicaciones no están diseñadas para atender emergencias médicas u odontológicas.

Se concede al usuario una licencia limitada, personal, revocable, no exclusiva y no transferible para utilizar las aplicaciones conforme a estos términos y a las condiciones de la plataforma desde la que se obtengan.

Esta licencia no transfiere la propiedad de la aplicación, su código, diseño, marcas, textos, elementos gráficos o documentación.

El usuario conserva los derechos y responsabilidades que le correspondan sobre las radiografías, imágenes, nombres de estudios, identificadores, anotaciones y demás información que introduzca o seleccione.

El usuario declara que cuenta con los permisos, autorizaciones y bases legales necesarias para utilizar, almacenar y compartir cualquier información que permita identificar a una persona. Para docencia, demostraciones y pruebas se recomienda utilizar material anonimizado.

El usuario es responsable de evitar la incorporación o difusión no autorizada de información personal o relacionada con la salud.

6. Privacidad y almacenamiento

Las prácticas de datos se describen en las políticas de privacidad publicadas para cada aplicación. En las versiones actuales, los estudios se procesan principalmente de forma local en el dispositivo y no se envían automáticamente a servidores del desarrollador.

Consultar las políticas de privacidad.

YOM Apps no controla las prácticas, disponibilidad o seguridad de servicios externos que el usuario decida utilizar.

No se permite utilizar las aplicaciones o el sitio para actividades ilícitas, para vulnerar derechos de terceros, para distribuir información obtenida sin autorización, para intentar comprometer la seguridad del software o para presentar resultados generados por la aplicación de forma engañosa.
