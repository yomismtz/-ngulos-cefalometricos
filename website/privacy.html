Política de privacidad de YomCeph

Última actualización: 11 de septiembre de 2026. Esta política describe YomCeph Desktop v0.12.5 y el sitio público del proyecto.

Resumen

YomCeph no requiere cuenta, no incluye anuncios, no usa analítica de uso del desarrollador y no sube automáticamente radiografías, datos de pacientes, landmarks ni resultados.

El trabajo clínico y de investigación se procesa localmente. Las únicas conexiones de red de YomCeph Desktop v0.12.5 son las necesarias para consultar y, con autorización del usuario, descargar actualizaciones oficiales desde GitHub Releases.

Datos que puede manejar la aplicación

YomCeph trabaja con información que el usuario introduce o selecciona: radiografías e imágenes, archivos PDF, identificadores de caso, edad, fechas, sexo registrado, identidad de género opcional, país o institución si el usuario decide registrarlos, grupos del estudio, landmarks, calibración, resultados cefalométricos, avisos de control de calidad, estado de elegibilidad, motivos de exclusión y metadatos del protocolo.

Una radiografía y los datos asociados a un paciente pueden constituir información personal y de salud. Para docencia e investigación se recomienda utilizar identificadores codificados y radiografías anonimizadas siempre que sea posible.

Finalidad

Los datos se utilizan únicamente para las funciones que solicita el usuario: abrir y visualizar radiografías, colocar landmarks, calibrar, calcular mediciones, revisar control de calidad, guardar casos, documentar inclusión/exclusión, organizar investigaciones y exportar resultados.

Procesamiento y almacenamiento local

En Windows, YomCeph conserva la base de datos y los archivos de trabajo fuera de la carpeta de instalación, dentro del perfil local del usuario. La ruta principal actual es %LOCALAPPDATA%\YomCeph\ResearchData. Allí pueden existir la base SQLite, copias de radiografías asociadas a casos, imágenes importadas desde PDF, respaldos, preferencias visuales y archivos temporales de actualización.

Separar los datos de la carpeta del programa permite actualizar o reinstalar YomCeph sin sustituir automáticamente la base clínica. Desinstalar la aplicación no elimina por defecto la carpeta de datos del usuario.

Sitio web público

El sitio de YomCeph es estático y no incorpora cookies publicitarias, píxeles de seguimiento ni analítica propia de YomCeph. Las descargas se sirven desde GitHub Releases.

Al visitar el sitio o descargar un instalador, GitHub puede procesar los datos técnicos normales necesarios para prestar el servicio, como dirección IP, fecha/hora, agente de usuario y URL solicitada, de acuerdo con sus propias políticas. El sitio no tiene acceso a la base local de YomCeph ni a las radiografías guardadas en el equipo.

Comprobación y descarga de actualizaciones

YomCeph Desktop consulta automáticamente la API pública de GitHub Releases poco después de iniciar para saber si existe una versión nueva. Esa consulta no contiene radiografías, identificadores de pacientes, datos de casos, landmarks, protocolos ni resultados.

Si existe una versión más reciente, YomCeph informa al usuario y solicita confirmación antes de instalarla. El instalador y su archivo de verificación se descargan mediante HTTPS desde la publicación oficial. La aplicación calcula y compara el SHA-256 antes de ejecutar el instalador. Si hay un caso con cambios sin guardar, la instalación no comienza. Si no hay conexión, YomCeph continúa funcionando localmente.

Preferencias de personalización

YomCeph permite elegir tipografía, tamaño de letra y una de cinco paletas visuales. Estas preferencias se guardan localmente y no contienen radiografías, resultados ni identificadores clínicos.

La personalización sólo modifica la apariencia de la interfaz. No altera la radiografía, coordenadas de landmarks, calibración, fórmulas, referencias seleccionadas ni resultados.

Exportación y compartición

El usuario puede generar Excel, CSV, sintaxis .sps para IBM SPSS, imágenes u otros informes disponibles. Esos archivos sólo salen del flujo local cuando el usuario decide guardarlos, copiarlos o compartirlos.

Investigación

YomCeph permite definir protocolos con muestra, rango de edad, país/procedencia, criterios, grupos y variables cefalométricas. En v0.12.5 el investigador puede intentar el trazado antes de completar la ficha final del sujeto. Al finalizar, YomCeph puede derivar criterios objetivos de edad, país, landmarks requeridos y necesidad de calibración, y permite documentar causas radiográficas adicionales de exclusión.

Los motivos de exclusión se almacenan localmente junto con el caso para trazabilidad. Los casos excluidos pueden conservarse en la base, pero se distinguen de la muestra incluida. La aprobación ética, consentimiento/autorizaciones y base legal del tratamiento siguen correspondiendo al investigador y a su institución.

YomCeph no convierte automáticamente una medición cefalométrica en una enfermedad. Las referencias pueden variar según método, edad, sexo y población, y la interpretación clínica requiere juicio profesional.

Seguridad

YomCeph no cifra por sí sola todo el dispositivo. El usuario o su institución deben aplicar las medidas adecuadas al contexto: cuenta de Windows protegida, cifrado del equipo cuando proceda, respaldos autorizados, control de acceso y tratamiento adecuado de archivos identificables.

YomCeph advierte sobre cambios sin guardar antes de cerrar, abrir otro caso, cambiar de flujo o iniciar una actualización. Estas protecciones reducen el riesgo de pérdida accidental, pero no sustituyen las copias de seguridad.

Conservación y eliminación

Los estudios permanecen en el equipo hasta que el usuario elimina los registros o borra los archivos locales correspondientes. Si se desea retirar completamente los datos después de desinstalar YomCeph, debe revisarse y, si corresponde, eliminarse manualmente %LOCALAPPDATA%\YomCeph\ResearchData después de conservar cualquier respaldo necesario.

YomCeph no mantiene una copia clínica paralela en servidores del desarrollador.

Aviso médico

YomCeph es una herramienta educativa y de apoyo a investigación y trazado. No sustituye la evaluación clínica de un profesional sanitario y no debe utilizarse como único fundamento para diagnóstico o tratamiento. El control de calidad genera advertencias; no corrige automáticamente landmarks ni resultados.

Responsable y contacto

YomCeph es un proyecto mantenido en el repositorio público yomismtz/Cefalometria-. Para reportar incidencias técnicas o de privacidad puede utilizarse la sección Issues.
