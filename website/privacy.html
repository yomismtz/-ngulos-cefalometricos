Política de privacidad de YomCeph

Datos que puede manejar la aplicación

YomCeph trabaja con información que el usuario introduce o selecciona: radiografías e imágenes, identificadores de caso, edad, fechas, sexo registrado, identidad de género opcional, país/institución, grupos del estudio, landmarks, calibración y resultados cefalométricos.

Una radiografía y los datos asociados a un paciente pueden constituir información personal y de salud. Para docencia e investigación se recomienda utilizar identificadores codificados y radiografías anonimizadas siempre que sea posible.

Finalidad

Los datos clínicos o de investigación se utilizan para las funciones que solicita el usuario: abrir y visualizar una radiografía, colocar landmarks, calibrar, calcular mediciones, ejecutar control de calidad, guardar casos, organizar investigaciones y exportar resultados.

Procesamiento y almacenamiento local

YomCeph Desktop no requiere una cuenta y no sube automáticamente radiografías, datos personales, landmarks ni resultados a servidores del desarrollador.

La base de datos, las copias locales de radiografías, los protocolos y los historiales se almacenan en el equipo. YomCeph Desktop no incluye anuncios, analítica de uso ni telemetría del desarrollador.

Comprobación y descarga de actualizaciones

YomCeph Desktop puede consultar automáticamente la API pública de GitHub Releases al iniciar para saber si existe una versión nueva. La solicitud contiene únicamente información técnica normal de una conexión web —por ejemplo, dirección IP procesada por GitHub, agente de usuario y versión instalada— y no incluye radiografías, identificadores de pacientes, datos de casos, landmarks ni resultados.

Si hay una versión nueva, YomCeph solicita confirmación antes de instalarla. El instalador y su archivo de verificación se descargan mediante HTTPS desde GitHub y la aplicación comprueba su SHA-256 antes de ejecutarlo. Si existe un caso sin guardar, YomCeph no inicia la instalación. Si no hay conexión, la aplicación continúa funcionando localmente.

El tratamiento técnico realizado por GitHub durante la consulta o descarga está sujeto a las políticas de GitHub. Esta función existe únicamente para distribución y seguridad de versiones; no se utiliza para analítica.

Exportación y compartición

El usuario puede exportar Excel, CSV, sintaxis para IBM SPSS, imágenes o informes cuando corresponda. Esos archivos sólo salen del flujo local cuando el usuario decide guardarlos, copiarlos o compartirlos. El tratamiento posterior por otras aplicaciones o servicios depende de sus propias políticas.

Investigación

YomCeph permite definir protocolos con muestra, rango de edad, criterios de inclusión/exclusión, grupos y variables cefalométricas. La aplicación ayuda a separar casos incluidos, no elegibles y pendientes, pero la aprobación ética, las autorizaciones, el consentimiento y la base legal del tratamiento corresponden al investigador y a su institución.

YomCeph no convierte automáticamente una medición cefalométrica en una enfermedad. Las referencias pueden cambiar según método, edad, sexo y población.

Seguridad y conservación

Los estudios permanecen en el equipo hasta que el usuario los elimina o borra los archivos locales correspondientes. Deben aplicarse las medidas de seguridad apropiadas al entorno de uso: cuentas protegidas, cifrado del dispositivo cuando proceda, copias de seguridad autorizadas y control de acceso.

Las actualizaciones conservan la base de datos y las radiografías en el directorio de datos local, separado de la carpeta de instalación.

Aviso médico

YomCeph es una herramienta educativa y de apoyo a investigación/trazado. No sustituye la evaluación clínica de un profesional sanitario y no debe utilizarse como único fundamento para diagnóstico o tratamiento. El control de calidad genera advertencias; no corrige automáticamente landmarks ni resultados.

Responsable y contacto

YomCeph es un proyecto mantenido en el repositorio público yomismtz/-ngulos-cefalometricos. Para reportar incidencias puede utilizarse la sección Issues del repositorio.

Cambios futuros

Esta política se actualizará antes de incorporar cuentas, sincronización clínica, almacenamiento en la nube, telemetría, anuncios u otras funciones que transmitan información adicional fuera del equipo. La política publicada debe corresponder al comportamiento real de la versión distribuida.
